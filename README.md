# Cybersecurity Notes & Security+ Preparation

This repository is designed to build a strong foundation in cybersecurity while providing a structured learning path for the **CompTIA Security+ (SY0-701)** certification.

The notes and documentation in this repository serve both as a study guide during exam preparation and as a long-term technical reference for cybersecurity concepts.
