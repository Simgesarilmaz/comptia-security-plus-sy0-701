Virus Sub-Types (⚠️ Tricky on Exam)

  • Boot Sector — loads at boot time
  • Macro — embedded in documents
  • Polymorphic — changes decryption module each run
  • Metamorphic — completely rewrites itself
  • Encrypted — hides payload via encryption
  • Stealth — hides from AV detection
  • Armored — confuses analysis tools
  • Multipartite — boot sector + program virus
Rootkit: starts at Ring 1 (admin), escalates to Ring 0 (kernel) via DLL injection. Detect by booting from external drive!

Quick Reference & Tricky Topics

⚠️ Common Exam Traps

  • Piggybacking vs Tailgating: Piggybacking = with consent; Tailgating = without consent
  • IDS vs IPS: IDS logs only; IPS logs AND blocks
  • NGFW vs UTM: NGFW = single engine; UTM = multiple engines
  • Virus vs Worm: Virus needs host; Worm self-replicates no user needed
  • Encryption vs Hashing: Encryption reversible; Hashing one-way
  • FAR vs FRR: FAR = accepts impostor; FRR = rejects legit user
  • Symmetric vs Asymmetric: Symmetric = same key, faster; Asymmetric = key pair, slower
  • Data Owner: Business person, NOT IT dept
  • Rootkit Detection: Boot from external drive
  • Ransomware: Never pay the ransom

Cryptographic Attacks

  • Downgrade Attack — force older/weaker protocol (POODLE on SSL3)
  • Birthday Attack — find two inputs with same hash (collision)
  • Collision Attack — undermine hash integrity
  • Pass-the-Hash — use hash instead of plaintext password (Mimikatz)
  • Replay Attack — resend captured auth data (prevented by nonces)
